Kebijakan Privasi (Privacy Policy) - Kasir Gue

Terakhir Diperbarui: 24 Juli 2026

Aplikasi Kasir Gue berkomitmen penuh untuk melindungi privasi pengguna kami. Kebijakan Privasi ini menjelaskan bagaimana kami memperlakukan data Anda saat Anda menggunakan aplikasi seluler dan desktop kami.

1. Pengumpulan Informasi & Data

Aplikasi Kasir Gue adalah aplikasi berbasis Lokal-First (Offline-First). Ini berarti:

  • Kami TIDAK mengumpulkan, mengirim, atau menyimpan informasi pribadi, data transaksi penjualan, daftar produk, detail serial number, atau laporan keuangan Anda di server kami.
  • Semua data yang Anda masukkan ke dalam aplikasi disimpan secara lokal di memori penyimpanan internal perangkat Anda sendiri (IndexedDB / Local Storage).

2. Penggunaan Izin Perangkat (Permissions)

Aplikasi kami memerlukan beberapa izin perangkat untuk mendukung fungsionalitas kasir:

  • Kamera: Digunakan secara eksklusif untuk memindai barcode produk atau kode QRIS menggunakan kamera perangkat Anda. Kami tidak menyimpan atau mengirimkan gambar/video apa pun.
  • Penyimpanan (Storage): Digunakan untuk menyimpan database lokal produk Anda dan mengekspor laporan transaksi atau file nota dalam bentuk PDF/Excel ke perangkat Anda.
  • Internet: Digunakan untuk memuat font/style eksternal dan memproses pembaruan aplikasi jika terhubung ke jaringan.

3. Keamanan Data

Karena seluruh data transaksi dan produk disimpan secara lokal di perangkat Anda, keamanan data sepenuhnya berada di bawah kendali Anda. Kami menyarankan Anda untuk menjaga keamanan perangkat fisik Anda dari akses yang tidak sah.

4. Perubahan pada Kebijakan Privasi ini

Kami dapat memperbarui Kebijakan Privasi kami dari waktu ke waktu. Kami akan memberi tahu Anda tentang perubahan apa pun dengan memposting Kebijakan Privasi baru di halaman ini.

5. Kontak Hubungi Kami

Jika Anda memiliki pertanyaan tentang Kebijakan Privasi ini, silakan hubungi kami melalui email di: support@kasirgue.store
